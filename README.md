# Dota Pick’em All

Dota Pick’em All — университетский проект по разработке веб-ассистента для драфта в Dota 2. Пользователь указывает союзных и вражеских героев, баны и роль следующего пика. Ассистент предлагает до трёх доступных героев и объясняет, как каждый из них сочетается с союзниками, чем полезен против соперников, какие риски есть у пика и какие предметы стоит рассмотреть.

За разные части анализа отвечают специализированные агенты. Один оценивает актуальность героя в мете, второй анализирует синергии и контрпики, третий подбирает предметы для финалистов. Оркестратор запускает анализ, а агрегатор собирает результаты в рекомендацию.

## Статус и объём MVP

Проект на стадии проектирования. Первый прототип позволит вручную собрать частичный драфт, выбрать роль и пересчитать рекомендации после изменения состава. В карточке героя планируется показывать разбивку баллов, аргументы, риски, предметы и версию данных.

Качество рекомендаций планируется сравнить с двумя базовыми методами на одинаковых сценариях драфта.
