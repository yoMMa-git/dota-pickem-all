# Этапы разработки

Этапы идут в порядке зависимостей. У каждого есть результат, который можно проверить.

| Этап | Задачи | Результат |
|---|---|---|
| 1. Контракты и ограничения | Описать входной драфт и ответ API. Проверять роль, списки героев и дубли. Отбирать допустимых кандидатов. | По частичному драфту можно получить список доступных героев. Тесты покрывают исключение выбранных и забаненных. |
| 2. Данные и базовые методы | Подготовить снимок для одного патча. Реализовать сортировку по винрейту и сортировку по винрейту с учётом матчапов. | Оба метода работают на одном снимке и соблюдают одинаковые ограничения драфта. |
| 3. Скоринг и объяснения | Реализовать агентов меты, синергий и контрпиков, оркестратор, скоринг и агрегатор. | API возвращает до трёх героев с разбивкой баллов, аргументами, рисками, патчем и версией данных. |
| 4. Предметы и интерфейс | Добавить агента предметов, экран драфта и карточки рекомендаций. Покрыть основной сценарий интеграционным тестом. | Можно ввести составы, баны и роль, посмотреть объяснения и предметы, затем изменить состав и повторить анализ. |
| 5. Оценка и демонстрация | Сравнить подходы, измерить задержку и вклад агентов. Подготовить демонстрационный драфт. | Есть результаты на фиксированном наборе сценариев и пример того, как меняются рекомендации при замене одного вражеского героя. |

## Проверка качества

Для сравнения используются одинаковые драфты и один снимок данных.

1. Ранжирование доступных героев по винрейту.
2. Ранжирование по винрейту с учётом матчапов.
3. Многоагентное ранжирование с оценками меты, синергий, контрпиков и роли.

Подготовить 30–50 тестовых сценариев отдельно от сценариев настройки весов. Допустимость пиков, уместность топ-3 и время ответа измеряются для всех подходов. Уместность оценивается по заранее заданным экспертным критериям. Для времени ответа фиксируются медиана и 95-й перцентиль. Для ответов с объяснениями проверяется доля фактических утверждений, подтверждённых статистикой или правилами.

Чтобы измерить вклад агентов, повторить сравнение, отключая по одному агенту скоринга и перенормируя оставшиеся веса.

## После MVP

- Персонализация по пулу героев и опыту игрока.
- Распознавание драфта из игрового клиента или изображения.
- Модель прогноза исхода матча на исторических данных.
- Мониторинг новых патчей.
- Рекомендации следующего бана.
